# Shared inference policy
The portable default lease is ~/.cache/ax-lab/runtime/inference.lock. Projects01/02/03 use the same user-owned location. AX_LAB_INFERENCE_LOCK can set an explicit absolute path; all clients on this host must agree. A checkout's parent directories never determine this location.
Private directory ownership/modes, NOFOLLOW, regular-file checks, flock and one in-process request enforce single flight. This does not coordinate unrelated clients which ignore the lease.
HTTP timeout does not establish server-side cancellation. A persistent .blocked marker beside the lease makes subsequent clients and restarted processes fail closed. There is no automatic retry/clear. If marker writing fails, the live process retains the lease; that fallback does not survive process termination.
Recovery: identify the exact owned timed-out request and verify it has completed using its request/log evidence. Ollama /api/ps showing a loaded model is not proof. Only then explicitly remove the exact private .blocked marker and restart the affected project process to clear its in-memory latch. Do not stop existing unrelated services or clear unknown markers. Source gold and access credentials never enter prompts.
