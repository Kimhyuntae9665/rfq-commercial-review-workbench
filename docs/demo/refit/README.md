# 현재 화면 캡처 출처

`00`부터 `07`까지는 합성 RFQ와 규칙 추출로 실제 headless Chrome 화면에서 재현한 9개 서로 다른 업무 상태입니다. 순서는 RFQ 선택 → 원문·인용 → 미확정 운임 → 수요 12 계산 → 사람 검토 이력 → 수량 변경으로 이전 검토 무효화 → 수요 30의 비용 순서 역전 → 200% 상당 재배치 → 모바일 390px입니다.

`checks.json`에 화면별 SHA-256, 59개 브라우저 검사, 모델 호출 0회를 기록했습니다. 비용·권한·인용·중복 검토·시나리오 변경 검사에는 저장된 원문과 백엔드가 사용됐습니다. 모델 출력을 재생하거나 새로 생성하지 않았습니다. 원본 screenshot의 성공 문구를 합성·수정하지 않았습니다.

`video/workflow.mp4`는 같은 실제 브라우저 세션의 데스크톱 viewport JPEG 7장을 순서대로 보여 주는 2초 유지 프레임 영상입니다. 연속 화면 녹화가 아닙니다. 프레임 SHA-256은 `checks.json`에, 원본은 `video/frames/`에 보존했습니다. 음성·추가 성공 오버레이는 없습니다.

이전 `../01`–`../12` 화면과 `../video/workflow.mp4`는 과거 UI의 기록입니다. 이 중 `08`–`12`는 당시 실제 모델 추출 결과를 사용했습니다. 현재 레이아웃을 보여 주는 자료로 표기하지 않습니다.

UI 기준: P09 v2 개발 화면의 흰색 2열 카드, 회색 바탕 `#f1f4f6`, 본문 `#142635`, 선택 버튼 `#173f60`, 경계 `#9eaeba`, 증거 블록 `#e7edf1`; 견적 표는 가로 스크롤을 허용하며 C 운임은 미확정으로 유지합니다. 데모 역할은 실제 인증이 아닙니다.
